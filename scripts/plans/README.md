# Zone plan georeferencing (offline)

Turns the official zone plan images (ViewZone.aspx Deep Zoom tiles) into `public/plans/<zid>.{webp,json}` + `index.json`.
Needs macOS (Apple Vision OCR via `swiftc`), Python 3 with `opencv-python-headless` and `numpy`, and a work directory `W`.

```bash
cd W
npx tsx /path/to/repo/scripts/plans/zone_plots.mts zone_plots.json   # plots per official zone from public/dev-snapshot (run from the repo root)
python3 -c "import json; m=json.load(open('public/dev-snapshot/meta.json')); json.dump({z['zid']:{'n':z.get('n'),'city':z['city'],'name':z['name'],'pid':z['pid'],'cityId':z['cityId']} for z in m['official']['zones']}, open('zone_counts.json','w'), ensure_ascii=False)"
swiftc -O -o tools/ocr_files tools/ocr_files.swift
python3 fetch_plans.py plans zones.tsv --all     # zones.tsv: zid, pid, cityId, city, name, flag, sectors (tab-separated)
zsh tools/batch_extract.sh                       # polygons + OCR per plan → plans/zone_<zid>.plots.json
zsh tools/pipeline.sh                            # register (zones with coordinates) → fill digits → export → index
```

Zones without coordinates: `chain.py` (same drawing as a registered neighbour), `match_roads.py` (OpenStreetMap roads from `osm_roads.py`),
`match_sat.py` (satellite edge correlation, only in a tight window around a known point), `georef_master.py` + `pins.py` (city master
plans with a satellite background → project pins), `control.py` (hand control points). Always check with `verify.py` before exporting.
Copy `export/*.webp`, `export/*.json` and `export/index.json` to `public/plans/`.

## Registrations and later tools (2026-11-10)

`reg/<zid>.json` is the registration of every installed zone (affine plan px → Web-Mercator metres; `scale_m_per_px` is
Mercator metres, ground = × cos(lat)). Keep them: several are hand-adopted and cannot be regenerated by `register.py`
(never run `pipeline.sh`'s register step over zones whose `how` is not `ocr`/`icp`; it would also undo the 6-parameter
fits of 3600/3603 and the re-placements of 3792, 4804, 4808). 3611 carries a manual shift, see its `note_shift`.

Screening: median(polygon ground area / official m²) per zone should be 0.82–1.14. Every zone outside that range was
misplaced or mis-scaled except 3779 (plots drawn larger than listed) and 3609 (undetermined). Check it after any new fit.

`contrib/` holds the tools written while finishing the zones (not all polished; paths may need adjusting):
- `F/road_match.py` — correlate a plan's road mask with graded roads in Esri imagery over scale/rotation/translation
  (the method that fixed West 28, Knowledge Village, Akhmim 16); `F/regroup.py` moves a chained group; `F/ov.py` lines overlay.
- `C/` — low-resolution plans (2048 px): whole-plan upscaled tile OCR with voting, re-segmentation of merged plots, resolver
  against the official number list. `C/export_plan.py` is the exporter to use (per-polygon `plot_id` is authoritative).
- `D/` — Arabic-Indic digit OCR (`ocr_files_ar.swift`), coordinate ↔ polygon matching (`identify.py`), polygon repairs.
- `A/` — 1600 px plans: marker-watershed plot extraction (`seg3.py`), slide georeferencing by road-edge correlation.
- `B/` — `extract_small.py` (10 px plots), `refine_osm.py` (chamfer refinement against OSM), `getosm.py` (OSM API fallback).
- `E/bg_match.py` (plan's own satellite background vs imagery), `G/recorner.py` (re-place without re-export), `H/diag.py`, `H/pin_reg.py`.

Not placed: Sheikh Zayed A–E (3594, 3596–3599), 15 May 3581 (uncertain candidate), Badr 4803 plot numbers (plan too coarse).
